## Try locally

Run `npm run dev` in this directory and use Vite's printed URL in a normal browser. In My fitness, start a routine, enter reps/load, complete a set, close the dialog and use Resume workout on Today. Refresh and verify the same set is retained. Finish records it in the diary. In My budget, move to the next month and choose Plan this month → Use last month's limits; review before saving.

Storage remains local to the browser/device/origin. Failures are shown in the app; keep the tab open and download a backup if saving fails. Cross-tab conflict handling, cloud sync and offline installation are future work. A real-phone pass and intended-user walkthrough remain the next verification steps.
